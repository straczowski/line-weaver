# 04.01 - Display SVG

> Enhance SVG display in the vectorized preview panel with proper scaling, loading states, and error handling.

---

## 📋 Context

The `PreviewCanvas` component currently handles both "Original" and "Vectorized" views. Basic SVG rendering exists via `dangerouslySetInnerHTML`, but it lacks:

- Proper responsive scaling to fit the container
- Visual feedback during processing
- Error state display
- Consistent styling with the original image preview

---

## 🎯 Goals

1. SVG scales responsively to fit the preview container while maintaining aspect ratio
2. Show loading indicator during vectorization processing
3. Display error messages when vectorization fails
4. Consistent visual treatment between original image and SVG preview

---

### Task 2: Fix SVG Responsive Scaling

**Problem:** Generated SVG has fixed dimensions:
```html
<svg width="800" height="600" viewBox="0 0 800 600">
```

**Solution Options:**

| Option | Approach | Pros | Cons |
|--------|----------|------|------|
| A | CSS on container | Simple, no SVG changes | Works because viewBox exists |
| B | Modify SVG string | Remove width/height | Requires string manipulation |
| C | Use `<object>` tag | Native browser handling | More complex, CORS issues |

**Chosen: Option A** - CSS-based scaling

The SVG already has `viewBox`, so we can override dimensions with CSS:

```css
.svg-container svg {
  width: 100%;
  height: 100%;
  max-width: 100%;
  max-height: 100%;
  object-fit: contain;
}
```

Update `SvgDisplay` wrapper to apply these styles.
